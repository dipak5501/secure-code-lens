# Secure Code Lens

A real-time security scanner for codebases, highlighting potential vulnerabilities and suggesting fixes.

## Trend

Security and code quality are becoming increasingly important as more businesses move to cloud-based solutions and open-source projects grow in complexity.

## Users

developers,security teams,project managers

## Setup

```bash
npm install
npm test
npm run build
npm start   # http://127.0.0.1:8787/
```

## Stop

Ctrl+C
